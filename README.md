# NetSnitch Combine

Нативный сетевой монитор и комбайн инструментов для Windows на **C# / WPF (.NET 10)**.

## Возможности
- **Монитор трафика приложений** (`Socket Polling + DNS + GeoIP/ASN`): список процессов, активные/закрытые соединения, живая лента трафика, лог DNS, трассировка и блокировка IP в Windows Firewall.
- **Сканер подсетей (LAN)**: автоопределение локальных подсетей (CIDR), параллельный Ping + ARP (`SendARP`), MAC-адрес, производитель (OUI), Hostname, Wake-on-LAN.
- **Сканер портов**: асинхронный TCP-сканер с профилями (`Top-47`, `Web/DB`, `1-1024`, свой диапазон) и Banner Grabbing.
- **Dig / DNS-инспектор**: запросы `A`, `AAAA`, `MX`, `TXT`, `NS`, `CNAME`, `SOA`, `PTR`, `SRV`, `CAA` по UDP/53 и DoH (Cloudflare / Google) + сравнение нескольких резолверов.
- **Слушающие порты (`LISTEN`)**: все локально открытые TCP/UDP порты с привязкой к PID и пути процесса.
- **Ping / WinMTR**: непрерывный мониторинг потерь и задержек по каждому хопу маршрута.
- **WHOIS / TLS / HTTP инспектор**: WHOIS + GeoIP/ASN, проверка SSL/TLS-сертификатов (цепочка, срок, SAN, шифр), HTTP-проба.
- **Менеджер фаервола**: просмотр и удаление правил `NetSnitch_Block_*` в Windows Defender Firewall.
- **Тихое автообновление**: проверка GitHub Releases при запуске, фоновая загрузка `.zip`/`.exe` и бесшумная замена файлов с перезапуском.

## Сборка
```powershell
dotnet build NetSnitch.csproj -c Release
```
